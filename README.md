# radar-retorno

Aplicativo para Windows desenvolvido para acompanhar preços de anúncios do Mercado Livre Brasil. O EliDevOliveira escolhe anúncios ou vendedores, informa palavras-chave e define o preço máximo que deseja pagar.

O aplicativo foi preparado para consultar a API oficial do Mercado Livre e mostrar os produtos que atendem aos filtros. Para divulgar uma oferta, o EliDevOliveira cadastra o link gerado na Central de Afiliados. O Radar prepara a mensagem com o preço e a identificação de publicidade. O EliDevOliveira escolhe o grupo e confirma o envio no WhatsApp.

Estágio atual: protótipo testado com dados simulados, aguardando acesso à API para validação com dados reais.
